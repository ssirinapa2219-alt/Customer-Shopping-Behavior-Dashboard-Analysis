# AI

# การทำความสะอาดข้อมูล (Data Cleaning)
ช่วยเขียนโค้ด Python สำหรับทำ Data Cleaning จากไฟล์ customer_shopping_behavior-clean.csv โดยตรวจสอบ Missing Values ลบข้อมูลซ้ำ และบันทึกไฟล์ใหม่
# การวิเคราะห์ข้อมูลเบื้องต้น (EDA)
ช่วยเขียนโค้ด Python สำหรับทำ Exploratory Data Analysis (EDA) ของชุดข้อมูล Customer Shopping Behavior
# การสร้าง Visualization
ช่วยแนะนำประเภทกราฟที่เหมาะสมสำหรับวิเคราะห์ข้อมูล Customer Shopping Behavior
# การพัฒนา Dashboard
ช่วยเขียนโค้ด HTML CSS JavaScript และ Chart.js สำหรับสร้าง Dashboard แสดงข้อมูลลูกค้า
# การปรับแต่งหน้า Dashboard
ช่วยออกแบบ Dashboard ให้ดูสวยงามและทันสมัย พร้อมตกแต่งกราฟให้เหมาะกับงานวิเคราะห์ข้อมูล
# การแก้ไขข้อผิดพลาด
ช่วยวิเคราะห์และแก้ไขข้อผิดพลาดจาก Python และ JavaScript ที่เกิดขึ้นระหว่างการพัฒนาโปรเจกต์
